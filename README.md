# X96 Локально 0.7.0

Приложение для Android-смартфона: понятные настройки приставки в домашней Wi-Fi-сети.
Устанавливается поверх 0.1.0 с сохранением ключа ADB и журнала восстановления.
Подключение 0.1.0 подтверждено пользователем на своей приставке; новые функции 0.4.0–0.7.0
на физической X96 пока не испытаны.


## Новое в 0.4.0

- Установка одного APK на приставку из системного выбора файлов смартфона.
  Вход: вкладка «Приложения» или карточка Projectivy → «Установить APK с телефона».
- Перед отправкой показываются название, пакет, версия, минимальный Android, размер
  и SHA-256. Для Projectivy принимается сертификат официальной GitHub-сборки.
- Файл копируется во временный закрытый кеш телефона, не читается целиком в RAM
  и удаляется после отмены, ошибки или завершения. Лимит одного APK — 256 МБ.
- Передача идёт напрямую установщику Android по ADB, без root-команд, выдачи разрешений,
  принудительного понижения версии и обхода подписи. Другие системные пакеты обновлять
  этим способом нельзя. После успеха дополнительно проверяется версия на приставке.
- Процент показывает подтверждённую передачу, а 100% означает ожидание установки,
  а не её успех. Текст результата появляется после ответа Android и проверки пакета.
- Поворот телефона не пересоздаёт Activity во время операции. После уничтожения процесса
  сохраняются вкладка, фильтр, поиск и адрес; соединение и установка сами не возобновляются.

Функция рассчитана на самостоятельный `.apk`. Архивы APKM/APKS/XAPK и split-наборы пока
не поддерживаются. APK с таким же package name, но другим сертификатом не сможет обновить
старое приложение; старое приложение не удаляется автоматически. Для обычных APK выбор
источника остаётся ответственностью пользователя, проверка пакета не является антивирусом.
У Projectivy закреплён текущий сертификат GitHub/XDA-сборки; другой канал подписи или будущая
ротация сертификата потребуют обновления политики, а не отключения проверки.

Если соединение прервать до завершения передачи, полный APK не будет доставлен. После
передачи всех байтов Android уже может завершить установку самостоятельно. Поэтому при
потере связи сначала проверьте установленную версию, не повторяйте действие вслепую.
Лимит одного потока установки — пять минут; ожидание отдельного ответа — до минуты.

Обновить Projectivy без ПК: скачать APK из [официальных релизов](https://github.com/spocky/miproja1/releases),
выбрать его на телефоне в X96 Локально, проверить диалог и подтвердить установку на приставку.
Приложение само APK из интернета не скачивает. Установщик и поведение интерфейса 0.4.0
на физической X96/смартфоне пока не испытаны; протокол проверен через имитацию ADB.

## Новое в 0.3.0

- Projectivy: определение установленной версии, HOME-задачи и перехвата, сравнение PID
  между замерами, явный запуск как системный HOME; восстановимый отказ от двойного перехвата.
- Root: проверка UID или запрос su на ТВ, компиляция/сброс компиляции кода Projectivy
  для Android 8–13, временный приоритет текущего процесса с записью исходного значения.
- Ещё пять переключателей: автоматическое время, фоновое сканирование Wi-Fi и BLE,
  отладочные наложения, таймер сна Android 30 минут. Поддержка проверяется по настройкам.
- Экран «Приставка»: сборка, плата, RAM, накопитель, доступный температурный датчик,
  названия видимых модулей Wi-Fi, версия Projectivy, root и копирование отчёта.
- Приложения можно открыть и закрыть при зависании; защищённые службы по-прежнему скрыты.
- Девять опций читаются за один ADB-запрос вместо отдельных соединений.

Исследование прошивки и порядок проверки повторного запуска: [docs/X96-RESEARCH.md](docs/X96-RESEARCH.md).
Root-действия требуют нажатия и подтверждения. Приоритет процесса не закрепляется навсегда:
его может изменить Android, а после перезапуска процесса настройка не переносится.
Сброс компиляции не восстанавливает старый ART-профиль, а сбрасывает состояние компиляции.
Службы других приложений сохраняются при отключении/возврате перехвата Projectivy.
Само приложение не отправляет внешние запросы; ссылки на источники открываются только
по нажатию в браузере. Новые функции на физической приставке пока не испытаны.

## Что изменилось в 0.2.0

Интерфейс разделён на четыре вкладки: «Улучшения», «Приложения», «Пульт», «Приставка».
Защищённые системные службы полностью скрыты из списка приложений. Записи собственных
изменений остаются доступны для восстановления, даже если политика защиты изменилась.
В списке показываются приложения с доступным действием; часть известных приложений
получила понятные названия. Для остальных отображается имя пакета.

### Улучшения: переключатели с описанием

| Опция | Что делает | Выключение |
|---|---|---|
| Быстрые переходы | Три масштаба анимации Android выставляются в 0.5 | Возвращает каждый исходный масштаб отдельно |
| Текст крупнее | Системный масштаб шрифта 1.15 | Возвращает исходный масштаб |
| Тихое меню | Выключает системные звуки нажатий | Возвращает исходную настройку |
| Без заставки | Выключает заставку Android | Возвращает исходную настройку |

Каждая опция сначала читает состояние приставки. Перед изменением исходные значения
сохраняются на телефоне синхронно. После применения результат читается заново.
Если прошивка не поддерживает настройку, переключатель недоступен. Если опция уже
включена вне приложения, показано «Уже включено на приставке»; приложение не придумывает
прошлое значение и не считает такую настройку своим изменением.

Выключение переключателя возвращает сохранённое состояние, а не условные заводские
значения. Отсутствовавшие до изменения параметры удаляются обратно. При обрыве или
частичном применении запись восстановления сохраняется. Кнопка «Вернуть прежние
настройки» последовательно отменяет только переключатели этого приложения. Если
возврат одной опции прервался, оставшиеся записи не теряются; можно повторить действие.

Быстрые переходы сокращают анимацию интерфейса, но не ускоряют сеть, декодирование
видео или игры. Размер шрифта поддерживают не все приложения. Отключение заставки
не отключает сон или питание телевизора; для OLED не стоит оставлять неподвижную
картинку надолго.

### Дополнительные действия

- Projectivy: выбор уже установленного лаунчера, проверка Home, возврат прежнего экрана.
  Заводской лаунчер не отключается; ограничения конкретной прошивки могут сохраниться.
- Освобождение места: `pm trim-caches 1G` просит Android удалить кеш при нехватке
  свободного места до целевого 1 ГБ. Если места достаточно, очистки может не быть.
  Android определяет объём очистки; приложение не показывает выдуманное число освобождённых
  мегабайт. Аккаунты, настройки и данные приложений не очищаются командой `pm clear`.
- Пульт: стрелки, OK, Home, Назад, воспроизведение/пауза, громкость и отключение звука.
  Громкость HDMI/телевизора зависит от схемы подключения и прошивки.
- Открытие системных настроек на ТВ: общий раздел, Wi-Fi, накопители.

## Подключение

1. Установите APK **на смартфон**, Android 8 или новее. Для обновления не удаляйте 0.1.0.
2. Телефон и приставка должны быть в одной доверенной домашней сети. Гостевая изоляция
   устройств может мешать подключению.
3. На приставке включите отладку по USB и сетевую отладку / ADB over network. Одного
   переключателя USB на некоторых прошивках недостаточно для открытия TCP-порта.
4. Введите IPv4 приставки из настроек её сети и ADB-порт, обычно 5555. Подтвердите запрос
   отладки на телевизоре, если он появится. На некоторых root-прошивках подтверждения нет.
5. После подключения панель адреса сворачивается, освобождая место для вкладок.
6. После работы закройте соединение и выключите сетевую отладку на самой приставке.

Автообнаружения и шестизначного сопряжения Android 11+ пока нет. Если прошивка не умеет
включать TCP ADB, приложение не может включить его удалённо без действующего доступа.

## Безопасность и восстановление

Только Wi-Fi и явно указанный частный числовой IPv4 (10/8, 172.16/12, 192.168/16).
Сокеты привязаны к Wi-Fi без переключения на мобильную сеть. Нет DNS-имён, внешних
загрузок, HTTP-клиента, удалённой конфигурации, облака, аккаунтов, аналитики и рекламы.
Никаких сторонних библиотек во время работы. Разрешения: INTERNET и ACCESS_NETWORK_STATE.
Ограничение адресов реализовано кодом приложения и не является сетевым экраном ОС.
Классический ADB не шифруется: используйте только доверенную домашнюю сеть.

Список доступных команд и настроек зафиксирован в исходниках. Произвольной shell-консоли,
загрузки скриптов, автоматической очистки и изменения системного раздела нет. В 0.3.0 добавлен явно запрашиваемый `su -c` только для фиксированных root-действий; root на телефоне не требуется.
Неизвестные системные пакеты остаются защищёнными. Отключаются только пользовательские
приложения и короткий список рассмотренных необязательных системных пакетов; все изменения
ручные, с подтверждением. Уже отключённые вне приложения пакеты автоматически не включаются.

Журнал и ключ ADB находятся в закрытом хранилище телефона, резервное копирование и перенос
отключены. Не удаляйте приложение и не очищайте его данные до восстановления изменений.
Обновление поверх предыдущей версии сохраняет журнал 0.1.0. Root-прошивка приставки или
root на телефоне остаются отдельными рисками. Собственная сборка не исключает все ошибки.

## Проверки и сборка

Сборка и подпись проверены. Автоматические тесты: 78 проверок протокола и политики,
59 проверок репозитория, возврата настроек и фильтрации списка, 52 проверки Projectivy/root и 95 проверок установки APK. В том числе: сохранение
до команды, отказ записи журнала, обрыв после частичного изменения, восстановление
новой сессией, возврат отсутствующих и разных исходных значений, неизвестная настройка,
чужое устройство по тому же IP, защищённые службы и запрет подстановки shell-команд.
Тестовый ADB-сервер работает через потоки памяти без реальной сети.

Для Linux: Java 17+ runtime и Python 3.

```bash
python3 tools/build.py --test-only
python3 tools/build.py
```

Скрипт скачивает официальные SDK/platform/build-tools и компилятор ECJ для компьютера,
проверяет закреплённые SHA-256, запускает тесты и создаёт неподписанный APK. Для подписи
задайте X96_KEYSTORE_PASSWORD и параметр `--keystore /path/key.p12`. Исходники не содержат
ключа подписи. Также приложен стандартный проект Android Studio / Gradle.
Физическая проверка новых функций, отображения интерфейса и перехват трафика на X96/телефоне
для 0.4.0 ещё не выполнены. Данные конкретной сборки — в BUILD-INFO.json.

## Сборка на GitHub

Исходники: https://github.com/Magral/X96

Workflow **Android APK** запускается на изменения main, pull request и вручную из Actions.
Официальные Actions закреплены по commit SHA. Для ускорения SDK и компилятор кешируются;
каждый скачанный инструмент дополнительно проверяется по закреплённой контрольной сумме.

- **Tests and unsigned APK** всегда проверяет тесты и компиляцию. Артефакт `X96-unsigned-*`
  не подписан, его нельзя установить поверх приложения.
- **Installable APK** работает только из main вне pull request и только при наличии
  секрета `X96_SIGNING_BUNDLE`. Артефакт `X96-installable-*` содержит APK для установки.
  Сертификат дополнительно сравнивается с ключом версий 0.1.0/0.2.0.
- Без секрета подписанный APK не создаётся; вместо подмены новым ключом выводится понятное
  сообщение. Текущий подписанный APK 0.2.0 остаётся доступен в чате.

### Однократное подключение подписи (Windows)

Понадобится GitHub CLI (https://cli.github.com/) с авторизацией `gh auth login`.
Распакуйте приватный архив `X96-local-signing-private.zip` в папку **вне репозитория**.
Из папки репозитория выполните в PowerShell:

```powershell
.\tools\setup-signing.ps1 -BackupFolder "C:\X96-private"
```

Замените путь на папку, где лежат `signing.json` и `x96-local.p12`. Скрипт передаёт ключ
и пароль в зашифрованный секрет GitHub через stdin, не печатает их и запускает workflow.
Не загружайте приватный архив, signing.json, ключ или пароль в файлы, Issues или чат
репозитория. Ключ в GitHub Secrets хранится отдельно от публичных исходников.

Артефакты сборок хранятся 30 дней; код и история коммитов — в репозитории. Автоматической
публикации релизов и передачи данных приставки на GitHub нет: Actions выполняет только
сборку исходников на сервере. Приложение по-прежнему работает локально.


### Версия 0.5.0 — понятная диагностика и проверка первого нажатия

- На вкладке «Приставка»: доступная RAM и свободное место в МиБ/ГиБ,
  время замера, температура с пояснением о датчике. Неизвестные значения не
  заменяются нулями; очистка кеша предлагается при свободном месте менее 1 ГиБ.
- В «Улучшениях»: после загрузки ТВ сохраните замер **до** первого нажатия
  пульта, нажмите кнопку пульта и выберите **сравнение после**. Проверка только
  читает данные, не запускает HOME и не меняет настройки.
- Идентичность процесса определяется по boot_id, PID и starttime, а не по
  одному PID. Перезагрузка, смена процесса и недоступные сведения различаются.
  boot_id остаётся в памяти телефона и не включается в копируемый отчёт.
- Сравнение показывает изменение RAM всей системы; оно не устанавливает
  причину сбоя и не обещает его исправление. Результат включён в отчёт,
  сбрасывается при отключении. Изменение версии/HOME/перехвата между замерами
  отмечается отдельно. Замеры не атомарны: состояние системы может меняться
  во время чтения.
- 34 новых проверки разбора показателей, неполных данных, повторного PID и
  перезагрузки; всего 318 проверок. Испытание на физической приставке требуется.

Семантика MemAvailable: [документация ядра Linux](https://www.kernel.org/doc/html/v6.15/filesystems/proc.html).


### Версия 0.6.0 — компиляция приложений и сравнение запуска

Вкладка «Приложения» → выбранное пользовательское приложение →
«Оптимизация и замер запуска»:

- **Замер запуска** закрывает и открывает приложение на ТВ после подтверждения.
  Показывает Android TotalTime в миллисекундах и разницу с предыдущим замером
  того же приложения в текущем подключении. Это время запуска экрана, а не
  готовности видео/сетевого контента. Изменение кеша, версии приложения и фоновой
  нагрузки может повлиять на результат; один замер не доказывает эффект.
- **По использованию** (`speed-profile`): использует накопленный профиль кода.
  Если профиля нет, заметного эффекта может не быть.
- **Полная компиляция** (`speed`): больше работы и места; ускорение не гарантировано.
- **Убрать предварительную компиляцию** (`verify`): сохраняет локальный профиль;
  Android сможет снова оптимизировать код. Это не точный откат к прежним артефактам.

Компиляция работает только с подтверждённым root на Android 8–13. Системные
пакеты, лаунчеры и защищённые приложения исключены; у Projectivy остался
отдельный инструмент на вкладке «Приставка». Перед каждым действием проверяется
идентичность приставки и доступность приложения. Неизвестный HOME блокирует
действие. Перед компиляцией требуется не менее 1 ГиБ свободного места
(консервативное правило приложения, не требование Android и не гарантия).

Нет массового запуска, автооптимизации, очистки данных или профилей. Прерывание
соединения не гарантирует отмену компиляции на ТВ; повторной команды автоматически
не будет. Ответ Android `Success` означает завершение команды, а не доказанное
ускорение. Замер отклоняется при предупреждениях, неверной Activity или явно
указанном WARM/HOT-запуске. При недоступных данных результат не выдумывается.

Исследование и ограничения: [docs/OPTIMIZATION-0.6.md](docs/OPTIMIZATION-0.6.md).


### Версия 0.7.0 — меньше задержек при чтении состояния

Обычное обновление состояния теперь открывает **2 ADB-сеанса вместо 10**:
основные сведения считываются одной фиксированной командой, настройки — второй.
Это сокращает количество подключений и RSA-авторизаций; фактическое ускорение
на конкретной Wi-Fi-сети ещё нужно проверить. Команды Android продолжают
выполняться последовательно. Новых настроек самой приставки в этом выпуске нет.

Перед каждым изменением по-прежнему читается свежее состояние и проверяется
идентичность устройства. Сведения не подменяются кешем. Снимок не атомарен:
приложения могут устанавливаться во время чтения; противоречивые списки
блокируют действие и требуют обновления.

Каждый из девяти разделов имеет случайную метку и отдельный код завершения.
Отсутствующий, обрезанный, переставленный или неуспешный раздел не принимается.
Повреждённые строки пакетов и несогласованные списки системных/отключённых
приложений не игнорируются. Ошибка необязательных настроек делает переключатели
недоступными, сохраняя корректно считанные основные сведения.

Тесты включают исполнение собранной команды в настоящем POSIX shell с
подставными командами Android, отказ промежуточной команды, обрыв ответа,
неверные списки, смену приставки и проверку количества ADB-вызовов.
