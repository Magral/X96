# Оптимизация X96 Max+ Ultra: версия 0.6.0

Дата исследования: 2026-11-06. Известная конфигурация пользователя: 4/64,
Android 11, root. Точные ревизии платы/сетевого модуля не подтверждены.

## Что внедрено

Штатная покомпонентная ART-компиляция для выбранного пользовательского пакета:
`cmd package compile -m speed-profile -f PACKAGE`, `speed`, `verify`.
Фильтры выбираются из закрытого перечисления; имя пакета проверяется,
системные пакеты и домашние экраны исключаются. Перед командой есть проверка
версии Android, root и свободного места. Диапазон поддержки намеренно ограничен
API 26–33: начиная с Android 14 управление dexopt перенесено в ART Service.

Отключение предварительной компиляции через verify сохраняет профиль;
это не побайтовое восстановление прежнего состояния. Существующий отдельный
сброс Projectivy через --reset также очищает локальный профиль — это уточнено
в подтверждении. Ни одна команда не читает учётные записи и не очищает данные.

Замер использует force-stop и am start -W для выбранной Activity после явного
подтверждения. Время TotalTime показывает запуск экрана Android. Контент может
догружаться после этого. Измерения не являются контролируемым бенчмарком:
кеш ОС сохраняется, частоты и температура меняются, версия и фоновые задачи
не фиксируются. Сравнение между подключениями не сохраняется.

## Что не добавлено и почему

- Постоянная очистка RAM/drop_caches: ядро само освобождает кеш, повторное чтение
  создаёт нагрузку на CPU и накопитель. Нет оснований считать это ускорением.
- Отключение термозащиты и принудительные максимальные частоты: для конкретной
  ревизии нет подтверждённых тепловых измерений и безопасных пределов.
- Глобальные изменения LMKD, swappiness, zRAM и Dalvik: требуют измерений на
  реальной прошивке; 4 ГБ RAM само по себе не определяет подходящие значения.
- Автоматическое закрытие приложений: нарушает воспроизведение, VPN и сервисы.
- Новая прошивка: название X96 Max+ Ultra 4/64 не гарантирует совместимости
  сетевого модуля и загрузчика. Здесь нет прошивки разделов.

на подставном ADB/TV; ускорение на X96 пользователь должен измерить отдельно.
